# おりーぶ庵 AI-OS

AI社員が働く会社画面。障害福祉サービス事業（共同生活援助ほか）の業務を、画面上のAI社員が実際に処理します。

**公開URL**: https://olive-ai-os.netlify.app/ai-os.html （mainへのpushで自動デプロイ）

## 実装済みの業務（本物）

| 業務 | 内容 |
|---|---|
| シフト集計 | シフト希望フォーム(GAS)から取得→日別集計・人手不足検出→「シフト集計」Excelへ反映 |
| 変更届 | 下書き生成／様式へのトークン差し込み／大阪市「様式第3号（変更届）」へ直接記入 |
| 個別支援計画書 | ポチパス様式1-1のインポート・編集・エクスポート（連携用データ列にも書き込み） |
| 付表12 | 大阪市「共同生活援助事業所の指定等に係る記載事項」のインポート・編集・エクスポート |

すべてのExcel書き出しは**元様式の書式（罫線・結合・列幅・印刷設定）を完全保持**します（JSZipによるセル値のみの直接編集方式）。詳細ルールは `CLAUDE.md` を参照。

## 構成

- `ai-os.html` … 1ファイル完結のアプリ本体（外部ライブラリ：SheetJS＝読取専用・JSZip）
- `netlify.toml` … 公開設定（`/` → `/ai-os.html`）
- `CLAUDE.md` … 開発ルール（元フォーマット完全維持ほか）

※シフト希望フォーム本番は別リポジトリ [`olive-an/olive-anshift`](https://github.com/olive-an/olive-anshift)。
