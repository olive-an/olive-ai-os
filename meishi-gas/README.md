# 名刺アプリ Googleドライブ連携（無料の文字読み取り＋名刺データの共有）

Claude APIを使わず、Googleドライブの文字認識で名刺を読み取り、名刺のデータをみんなで共有するための設定です。
1人のGoogleアカウントで1回だけ設置します。料金はかかりません。

できること
- 名刺の写真を、Googleの文字認識で文字にする。
- 名刺のデータを、そのアカウントのスプレッドシート「名刺データ（おりーぶ庵）」に保存する（共有モード）。
- 名刺の写真を、ドライブの `AI-OS2026/名刺画像` に保存する（共有モード）。スマホでもパソコンでも、同じ名刺が見られる。

注意（先に読んでください）
- 名刺は取引先など第三者の個人情報です。設置するのは個人のGoogleアカウントで、スプレッドシートとフォルダは共有設定を変えず、そのアカウントの持ち主だけが見られる状態のままにします。
- 共有は「URLと合言葉」で行います。URLと合言葉を知っている人は、全員が全名刺を見られ、書き換え・削除もできます。教える相手は、必要な職員だけにしてください。
- 合言葉（TOKEN）はパスワードと同じです。長めの英数字にして、チャットやメールで広げないでください。職員が辞めたら、合言葉を変えます（下の「合言葉を変えるとき」）。
- 名刺の写真は、読み取りのためGoogleに送られます。
- このファイルをGitHubに置くときは、合言葉を入れた状態にしないでください（この `Code.gs` は書き換え前の見本です）。

## 設置手順（パソコンで行うのがおすすめです）

1. https://script.google.com を開き、「新しいプロジェクト」を作ります。名前は「名刺読み取り」など。
2. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の内容を貼り付けます。
   一番上の `TOKEN` の行の日本語を、自分だけの合言葉（英数字12文字以上）に書き換えます。
3. 左の「サービス」の「＋」を押し、「Drive API」を選んで「追加」します。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
   「デプロイ」を押し、権限の確認が出たら承認します（初回のみ。「安全でないページ」と出た場合は「詳細」から進みます）。
5. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピーします。
6. 名刺アプリ（meishi.html）の「設定」→「Googleドライブ連携」に、URLと合言葉を入れて「接続テスト」を押します。
7. 共有するときは、同じ画面の「名刺データをスプレッドシートで共有する」をオンにして「保存」を押します。最初の保存で、スプレッドシートとフォルダが自動で作られます。
8. すでにこの端末だけに保存した名刺がある場合は、「この端末だけにある名刺を共有に送る」を押します。
9. 他の職員の端末にも、手順6と7で同じURLと合言葉を入れます。

共有モードの動き
- 起動したとき、と「共有データを更新」を押したときに、最新の名刺を読み込みます。
- 保存・削除は、すぐ共有に反映されます。同じ名刺を同時に直したときは、あとから保存した方が残ります。
- 写真は、名刺を開いたときに読み込みます（初回だけ少し待ちます）。
- 通信できないときは、その端末に保存済みの内容を表示します。保存・削除は通信が必要です。

## コードを書き換えたとき

「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」にして「デプロイ」します。
（これをしないと、書き換えが反映されません。）

## 合言葉を変えるとき

1. Apps Scriptで `TOKEN` の行を書き換え、「デプロイを管理」から新バージョンをデプロイします。
2. 名刺アプリの設定で、使い続ける人の端末の合言葉を新しいものに入れ直します。
